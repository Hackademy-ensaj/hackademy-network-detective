# 🔍 Mission 2 — Services réseau

## 🎯 Objectif

Découvrir les ports utilisés par les services d'une machine.

## 1. Afficher les ports

ss -tuln

## 2. Comprendre le résultat

Expliquer :

- TCP
- UDP
- LISTEN
- Local Address
- Port

## 3. Identifier un port

Donner un exemple de lecture :

0.0.0.0:22
127.0.0.1:631
etc.

## 🧠 À retenir

Un port permet à un service réseau de recevoir des connexions.
